The useful failure

Prediction is not preservation.

We tested the simple idea directly: use recent weight history to jump neural training forward. On the first real CIFAR-10 CUDA run, the scalar linear nowcaster was not faster. It was about 36% slower and required 33% more backpropagation to cross the same 59% accuracy threshold.

Question 1

Forecasting

Where is the optimizer likely to go next?

θ(t+h) ≈ F(θ(t−k:t))

A nowcaster treats recent training as a trajectory to extrapolate. That can work when the path is locally coherent. It can also blend distinct viable directions into a destructive average.

Question 2

Compatibility

How can a proposed update become structure without destroying preserved computations?

Δ = Δcompatible + r

ThirdWay keeps the optimizer as proposer, absorbs the compatible component, and treats the signed residual r as geometric debt that may justify route separation or growth.

The nowcaster asks where the weights are going. ThirdWay asks what the substrate can safely absorb.

What this result does — and does not — say

It does say

For this seed and this matched PyTorch CIFAR-10 control, independent linear weight extrapolation was a clear practical loss.

It does not say

It does not refute the learned Weight Nowcaster Network. This repository did not reproduce WNN's learned forecaster.

It redirects us

The main architectural question is no longer “can we forecast the next weights?” It is “can we preserve incompatible useful computations while learning continues?”

The next decisive experiment

Build a lethal average on purpose.

Construct two parameter states A and B that both implement useful computations, while their average fails. Then present alternating useful update directions to three systems: direct shared updates, trajectory forecasting/averaging, and ThirdWay compatibility decomposition with signed residual plus structural growth.

W_A works W_B works (W_A + W_B) / 2 fails Can compatibility + residual growth preserve both?

That experiment belongs in ThirdWay. This repository remains as the negative control that explains why.
